# Roadmap

Blocks planned for the free collection, roughly in order. Each new block ships with a README, tests, a demo entry and a build video.

## Next up

- [ ] **Filterable article list**: driven by the query index, with tag filters, search and pagination
- [ ] **Store / location finder**: locations from a spreadsheet, filter by region, optional map loaded in the delayed phase
- [ ] **Stats counter**: animates numbers when scrolled into view
- [ ] **Announcement banner**: dismissible, remembers the dismissal
- [ ] **Countdown timer**: for launches and events, with time zone support

## Later

- [ ] Related content (pages sharing tags, from the query index)
- [ ] Auto table of contents with reading time
- [ ] Charts from a spreadsheet (library loaded lazily)
- [ ] Image hotspots with tooltips
- [ ] Gallery with lightbox
- [ ] Multi-step form with progress indicator
- [ ] Testimonials with review schema
- [ ] Event calendar and job listings from spreadsheets

## Ideas and requests

Open an issue with the block you'd like to see and a sketch of how authors would fill it in.
