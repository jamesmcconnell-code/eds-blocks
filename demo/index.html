FAQ

What is Edge Delivery Services?

A way to build very fast websites where authors write in documents or spreadsheets and developers ship small, self-contained blocks.

Do these blocks need any dependencies?

No. Each block is a single JavaScript file and a single CSS file. Copy the folder into your project and you are done.

Will they hurt my Lighthouse score?

They are built to keep it at 100: no libraries, no layout shift, and nothing heavy in the eager phase.
